[CORE FEATURES]

=== FEATURE 1: MASTER PASSWORD ===

On first launch:

* Ask user to create Master Password
* Hash password using a secure algorithm
* Store only hash
* Never store plain text password

On future launches:

* Require Master Password login
* Deny access if password is incorrect
* Allow only 3 login attempts

Requirements:

* Use readline with muted / hidden input for password entry (do not echo characters)
* Validate password strength
* Use crypto.scrypt or crypto.pbkdf2 for secure password hashing with a random salt

Password Rules:

* Minimum 12 characters
* Uppercase letter required
* Lowercase letter required
* Number required
* Special character required

=== FEATURE 2: PASSWORD VAULT ===

Each credential record:

{
id,
website,
username,
password,
notes,
created_at,
updated_at
}

Features:

* Add Credential
* Edit Credential
* Delete Credential
* List Credentials
* Search Credentials

=== FEATURE 3: ENCRYPTION ===

All sensitive data must be encrypted.

Encrypt:

* usernames
* passwords
* notes

Requirements:

* Use AES-256-GCM encryption via Node.js crypto module
* Generate encryption key securely
* Protect stored credentials
* Store IV / auth tag with ciphertext as needed for correct decryption

Never store plain text passwords.

=== FEATURE 4: SEARCH ===

Allow searching by:

* Website
* Username

Search must be case-insensitive.

=== FEATURE 5: PASSWORD GENERATOR ===

Provide built-in password generator.

User can choose:

* Length
* Include Symbols
* Include Numbers
* Include Uppercase

Generate cryptographically secure passwords.

Use crypto.randomInt / crypto.randomBytes.

=== FEATURE 6: FILE STORAGE ===

Persist all data locally.

Files:

master.json
vault.json
key.key

Requirements:

* Automatic save
* Automatic load
* Proper error handling
* Corruption detection

=== FEATURE 7: EXPORT ===

Allow exporting vault data.

Export formats:

* JSON

Before export:

* Require Master Password verification

=== FEATURE 8: SECURITY ===

Implement:

* Session timeout
* Login attempt tracking
* Secure key handling
* Input validation

Never print sensitive information unnecessarily.
